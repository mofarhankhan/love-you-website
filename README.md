# Love You Website 💖

A cute responsive single-page website.

## Features
- "I Love You" romantic landing card
- Yes and No buttons
- No button runs away on hover/touch/click
- Responsive mobile + desktop layout
- Yes button opens a romantic note
- Emoji confetti animation
- Replay button

## Run locally
Just open `index.html` in your browser.

For the best experience, you can also run a simple local server:

### VS Code
Install the "Live Server" extension and click "Go Live".

### Python
```bash
python -m http.server 5500
```
Then open:
http://localhost:5500

## Deploy
You can deploy this static website for free on:
- GitHub Pages
- Netlify
- Vercel

## Customize
Open `index.html` and change the note inside the `<div class="note">...</div>`.
